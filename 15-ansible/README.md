# Project 15 - Ansible Server Configuration

## Goal

Remote configuration automation with Ansible.

## Tasks

1. Set up an Ansible controller.
2. Install a web server using a playbook. This project uses [web.yml](./web.yml) to install nginx.

## Deliverable

Proof screenshots. Suggested evidence: `ansible --version`, the successful playbook run and the page served by nginx. Save these in `p15_output/`.
